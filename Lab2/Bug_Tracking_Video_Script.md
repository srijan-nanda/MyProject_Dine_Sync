# Bug-log_Project – Video Script (about 4–5 min)

Record your screen with **Cmd+Shift+5 → Record Entire Screen** on Mac. Use light mode and accept the cookie banner first.

| # | Time | Do this in Jira | Say |
|---|---|---|---|
| 1 | 0:00 | Show your name or profile in Jira | "Srijan Kumar, PES1UG24CS467. Lab 2 bug tracking for PS #36, Restaurant Table Booking." |
| 2 | 0:15 | **+ Create project → Software development → Bug tracking** template. Name it `Bug-log_Project`, then Create. | "I'm creating a project with the Bug tracking template." |
| 3 | 0:45 | **Create** → Work type **Bug** → BUG-1. Fill in the Summary, then paste Steps / Expected / Actual / Environment into the Description. Set Priority to **Highest**, set Assignee to yourself, add a label `PS36`. | "Logging a double-booking defect with steps to reproduce, expected and actual results." |
| 4 | 1:45 | Create BUG-2 to BUG-6 quickly. You can pre-fill them before recording and just show one being created. | "Remaining bugs cover availability sync, validation, prep time, cancellation, and payment security." |
| 5 | 2:30 | Open the **List** view. Show all 6 bugs with their priorities. | "Here's the full bug log, prioritized by impact." |
| 6 | 2:50 | Open BUG-1 → **Link work item** → "relates to" the FR-001 story in your Scrum project, if Jira allows it. Otherwise add a comment saying "Relates to FR-001 (SRB36-3)". | "Each bug is traced back to its requirement." |
| 7 | 3:10 | Open BUG-1 and add a comment: "Fix: lock the table slot during confirmation." Move it **To Do → In Progress → Done**. | "Showing the bug lifecycle from report to resolution." |
| 8 | 3:40 | On the **Board**, drag BUG-2, 3 and 5 to Done, BUG-4 to In Progress, and leave BUG-6 in To Do. | "Final state: 4 fixed, 1 in progress, 1 open." |
| 9 | 4:10 | Optional: use **Filters** to show `type = Bug AND priority = Highest`. | "Filtering the critical bugs." |
| 10 | 4:30 | End on the Board view. | "That completes the bug-tracking workflow." |

After recording, save the video as `Bug_Tracking_Video.mov` and keep it under 25 MB if you can, so GitHub's web upload accepts it. Also save one screenshot of the final board as `Bug_Board.png`.
